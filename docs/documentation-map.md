## Maintaining the catalog

When adding or renaming Markdown, update this inventory and verify every local
file/anchor target. Preserve historical evidence. Do not refresh dated counts
or issue states by replacing their dates; add a new scoped reconciliation.
Wiki publication is generated by `.github/scripts/sync-wiki.sh` after the normal
merge gate. A draft documentation PR does not update the live Wiki.
