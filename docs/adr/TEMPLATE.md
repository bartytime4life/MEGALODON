# ADR-NNNN: Short decision title

Status: **Contract only.** This file is a template, not a decision. A copied
record must set its own honest status header before review.

Decision state: **Proposed**. Other states require an explicit dated review
receipt; do not infer acceptance from a test, PR merge, or green workflow.

- Date: YYYY-MM-DD
- Owner/reviewer: named role or `not_recorded`
- Exact source basis: commit/tree or `not_recorded`

## Context and decision needed

Describe the operator or engineering problem and the existing contract or issue
that makes a choice necessary. Separate observed behavior from assumptions.

## Proposed decision

State one bounded choice and its authority limits. If there is no decision yet,
say so and list the missing evidence.

## Alternatives considered

List the real options and the reasons for deferring or rejecting each. Do not
invent a comparison result or platform receipt.

## Consequences and controls

Name affected paths, compatibility obligations, negative controls, reversibility,
and any operator/security review needed before implementation or use.

## Evidence and remaining gate

Record exact commands, outcomes, skips, source identity, and reviews when they
exist. State what the record does **not** establish, including host, sensor,
release, and platform claims when relevant.

## Supersession

Link a replacement ADR here if this decision is later superseded. Preserve the
original record and its dated evidence.
